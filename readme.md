# (task/todo list) application 
## this is an app where you can add and delete tasks ,also indecate if the task is done or not 
 

 ## 🚀 Installation & Setup

Make sure you have [Node.js](https://nodejs.org/) installed, then follow these steps:

### necessary steps before working:

```bash
* if you downloaded the exe file you dont need the steps start it with : .\todo.exe
1- download the app on you terminal by **npm install -g git+https://github.com/mohammadAK09/todo-app.git** or **git clone [https://github.com/mohammadAK09/todo-app.git](https://github.com/mohammadAK09/todo-app.git)**
2- cd todo-app
3- download npm : npm install
4- npm link
5- Windows Note: If running todo directly in the project directory opens a script pop-up, you can force the executable by typing todo.cmd instead, or run it from any other directory!
 
 for user guide type : todo --help or todo -h
