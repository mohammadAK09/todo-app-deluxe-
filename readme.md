# (task/todo list) application 
## this is an app where you can add and delete tasks ,also indecate if the task is done or not 
 

 ## 🚀 Installation & Setup

Make sure you have [Node.js](https://nodejs.org/) installed, then follow these steps:

### 1. Clone the repository
```bash
git clone [https://github.com/mohammadAK09/todo-app.git](https://github.com/mohammadAK09/todo-app.git)
cd todo-app

## necessary steps before working:
1- download npm : npm install
2- npm link
3- Windows Note: If running todo directly in the project directory opens a script pop-up, you can force the executable by typing todo.cmd instead, or run it from any other directory!
 
 for user guide type : todo --help or todo -h
